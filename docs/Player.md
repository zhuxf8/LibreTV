# 播放器说明

LibreTV 使用 HLS.js + DPlayer 作为播放内核，支持 HLS（`.m3u8`）直链经服务端代理后播放。

## 键盘快捷键

| 按键 | 功能 |
|---|---|
| 空格 / `K` | 播放 / 暂停 |
| `←` / `→` | 快退 / 快进（5 秒） |
| `↑` / `↓` | 音量 + / - |
| `M` | 静音 / 取消静音 |
| `F` | 全屏 / 退出全屏 |
| `Esc` | 退出全屏 |

## 手势与交互

- **双击**：切换全屏 / 退出全屏。
- **长按**：在进度条上长按可显示精确时间提示（已修复旧版重复绑定监听的问题）。
- **选集 / 换源**：详情页多集与多源可在播放面板切换，切换时复用同一播放器实例。

## HLS 与代理

- m3u8 主列表与内层分片均经 `/proxy` 改写，确保分片地址也走代理（避免直链跨域 / 防盗链失败）。
- 代理会对 m3u8 做递归重写（默认最多 5 层，受 `MAX_RECURSION` 控制），并缓存（受 `CACHE_TTL` / `CACHE_MAX_AGE` 控制）。

## 豆瓣匹配

- 详情页可触发豆瓣信息匹配：当搜索结果命中多个候选时，已优化为**自动选择首个高置信度匹配**，减少误匹配与空白封面。
- 匹配失败时会回退到源站自带的海报 / 简介，不影响播放。

## 常见问题

- 部分非 HLS 的直链（如 `.mp4`）同样走 `/proxy` 转发，无需额外配置。
- 若播放卡顿，多为源站限速或网络问题，可尝试切换源 / 清晰度。
