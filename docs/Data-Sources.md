# 数据源配置

LibreTV **默认不包含任何视频源**。你需要自行添加采集站 / 苹果 CMS API 后才能搜索与播放。

## 支持的格式

主流「苹果 CMS V10」采集 API：

- 搜索接口：`https://你的源/api.php/provide/vod/?ac=videolist&wd=关键词`
- 详情接口：`https://你的源/api.php/provide/vod/?ac=detail&ids=视频ID`

部分源使用 `api.php/provide/vod/` 或 `index.php/...`，路径以实际为准。LibreTV 会自动拼接 `wd` / `ids` 参数并发起请求。

## 添加步骤

1. 打开站点 → 「设置」→「数据源 / 自定义接口」；
2. 接口地址填写到 `api.php/provide/vod` 这一级（**不要**带 `?ac=...` 后缀，参数由程序自动补）；
3. 保存后回到首页搜索，验证是否有结果；
4. 可添加多个源，搜索结果会合并去重。

## 示例

```
https://example.com/api.php/provide/vod
```

## 排错

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 搜索无结果 | 接口地址填错（带了 `?ac=` 或少了 `provide/vod`） | 只填到 `api.php/provide/vod` |
| 报 401 / 未授权 | 代理鉴权失败 | 确认密码 / `PROXY_SECRET` 配置正确，函数环境已重新部署 |
| 详情能搜到但播放报错 | 该源返回的播放地址需代理，但直链被防盗链 | 确保走 `/proxy`；部分源需带 Referer，可在 `USER_AGENT` / 请求头调整 |
| CORS 报错 | 不应出现 | 所有请求经服务端代理转发，已规避浏览器跨域；若出现请检查部署是否正确 |
| 返回非 JSON / 乱码 | 该源非苹果 CMS 标准格式 | 更换为标准兼容源 |

## 注意事项

- 请仅添加你**有权使用**的源，遵守源站与使用地法律法规。
- 源的稳定性、内容合规由源站负责；项目仅做转发，不缓存视频内容。
- 多个源可能返回重复影视，前端已做标题去重，最多保留前若干条（避免长列表卡顿）。
